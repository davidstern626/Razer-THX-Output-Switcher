# Razer THX Output Switcher

**非官方 Razer THX Spatial Audio 输出设备切换工具**

**An unofficial output device switcher for Razer THX Spatial Audio.**

---

## 🇨🇳 中文介绍

### 项目简介

Razer THX Output Switcher 是一款适用于 Windows 的轻量级工具，旨在快速切换 Razer THX Spatial Audio 所使用的物理音频输出设备。

例如，在电脑扬声器与无线耳机之间切换时，无需每次手动进入 Razer 软件选择输出设备。

### 主要功能

* 一键切换已配置的音频输出设备。
* 支持通过图形化设置界面管理设备。
* 支持选择参与切换的设备及其顺序。
* 在条件允许时，同步 THX 软件界面的设备显示状态。
* 切换 THX 输出时，保持 Windows 默认播放设备为 THX Spatial Audio。

### 系统要求

* Windows 64 位系统。
* 已安装并能够正常工作的 Razer THX Spatial Audio 及其相关软件。
* 至少两个兼容的物理音频输出设备。

### 使用方法

1. 下载 Windows 发布压缩包并完整解压。
2. 运行 `THX_Output_Switcher_Settings.exe`。
3. 选择需要切换的音频设备，保存并验证配置。
4. 运行 `THX_Output_Switcher.exe`，执行音频输出切换。

请保留压缩包中的完整目录结构，不要单独移动 EXE 文件。

### 当前版本

`v0.9.0-rc.1`

当前为候选版本，可能存在尚未发现的兼容性问题。不同 Razer 软件版本和音频设备环境下的实际表现可能有所差异。

## 🇬🇧 English

### Overview

Razer THX Output Switcher is a lightweight Windows utility designed to switch the physical audio output device used by Razer THX Spatial Audio.

It provides a convenient way to switch between speakers and headphones without manually selecting an output device in the Razer application each time.

### Features

* One-click switching between configured audio output devices.
* Graphical interface for device configuration.
* Configurable device selection and switching order.
* THX application UI synchronization when supported.
* Keeps THX Spatial Audio as the Windows default playback device during switching.

### Requirements

* 64-bit Windows.
* A properly installed and functioning Razer THX Spatial Audio environment.
* At least two compatible physical audio output devices.

### How to Use

1. Download and fully extract the Windows release ZIP.
2. Run `THX_Output_Switcher_Settings.exe`.
3. Select your preferred output devices, then save and validate the configuration.
4. Run `THX_Output_Switcher.exe` to switch the output device.

Keep the complete extracted directory structure intact. Do not move the executable files individually.

### Current Version

`v0.9.0-rc.1`

This is a release candidate. Compatibility may vary depending on the Razer software version and audio hardware configuration.
